# Privacy Policy — Attribute Xpress

This Privacy Policy describes the data practices for the **Attribute Xpress** application. To promote transparency and protect user privacy, this policy explicitly addresses the mandatory requirements of the Autodesk App Store.

### 1. Data Collection and Usage
Attribute Xpress does not collect, store, transmit, or process any personal information, telemetry, drawing geometry, or metadata. All application operations execute entirely offline and locally within Autodesk AutoCAD. No drawing data, block attribute values, or user configurations are ever transmitted to external servers or remote endpoints.

### 2. Third-Party Sharing
Attribute Xpress does not share any information with third parties. There are no integrated tracking SDKs, analytics frameworks, cloud services, or external advertisements included in the software.

### 3. Data Retention and Deletion
Because no data is collected, stored, or transmitted remotely, there is no remote data retention. Any temporary session preferences or exported CSV files remain strictly under user control on the local filesystem and can be cleared or deleted at any time.

### 4. User Consent and Revocation
As no personal data is collected or stored, users can effectively revoke all consent at any time simply by uninstalling the plugin from their system.
